# Глав Един Надзор

Откройте `index.html` в браузере. Сохраните `style.css`, `script.js` и папку `img/` рядом с ним.

- На заставке красный индикатор мигает; «Остаться на сайте» открывает экспозицию.
- Нажатие на переднюю семейную фотографию заменяет её версией с разбитым стеклом.
- Во втором разделе буклет, шприц и чебурашка перетаскиваются мышью или касанием внутри области раздела; коробка остаётся на месте.
- Высота макета масштабируется вместе с шириной, без лишнего пустого блока.
- Нажатие на «соглашение» показывает приложенное изображение; «Подписать» закрывает окно и возвращает прокрутку. Кнопка только закрывает просмотр и не сохраняет подпись.
- Наведение на каждый сюжет СЖТ показывает соответствующую реплику в облачке рядом с Чебурашкой.
- В мобильной версии в начале горизонтально листается только длинная фотополоса, разбитая на три панели; семейные рамки остаются перекрывающейся композицией.
